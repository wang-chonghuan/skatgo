# SKATGO-111 ac

`tmp/ac.mjs` 用 Playwright 在本地构建版（55111）上跑，桌面 1280×820 和手机 375×812 各一遍：

1. **关卡格：** 20 个方块，没有逐题标题；状态正确（勾、叉、下一关、锁），答错次数在角上；「Aufgabe n spielen」按钮直达下一关。
2. **做题页**（返工 3 后）：
   - 和自由对局一样的全屏牌桌：没有网站顶栏，在各种屏幕尺寸上都正好一屏、不滚动；
   - 牌桌顶部一块信息板，有题号、标题（h1）和分数条；右上角是牌桌的退出按钮，退回题目列表；
   - 没有任务说明、信息栏（`skat-info`）、侧边面板（`skat-panel`）和叫牌记录（`skat-history`）；
   - 第 3 题起没登录时，登录卡浮在牌桌上。
3. **反馈**（返工 2 后）：
   - 出牌时不标对错，出错后也不停，由学员自己接着出，对手按最强打法应对，直到胜负已定；
   - 结束时牌桌上显示小卡（Gelöst + 关键牌，或 Nicht gelöst +「Dein Fehler: … Richtig war …」，以及下一关、Warum?、Noch mal）；
   - 「Warum?」点开前不显示解释。
4. **其余照常：** 第 3 关起要登录，没有控制台报错。
