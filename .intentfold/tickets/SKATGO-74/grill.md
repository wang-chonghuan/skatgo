# SKATGO-74 grill

Grill：human。下面 5 个问题一次问完，每题附建议和理由。

1. **自动事件全部关掉，只留页面浏览？**
   - **建议**：
     - 关掉 `$autocapture`、`$rageclick`、`$dead_click`、热图、网页性能（`$web_vitals`）和异常自动上报；
     - 保留 `$pageview` 和 `$pageleave`。
   - **理由**：
     - 洪水就来自这些自动事件。叫牌、出牌、收墩都是点击，连点还会触发 rageclick。
     - 行业通行做法是只发显式命名的事件（tracking plan）：每个事件有明确含义，漏斗和留存才看得清。
     - 自动捕获适合还不知道该看什么的早期探索，代价是噪音和事件费用。
     - 只排除牌桌也不划算：要给牌桌元素逐个加 PostHog 专用的排除标记（它常用的 `ph-no-capture` 还是 class 名，ui.md 禁止写 `className`），新加的控件很容易漏掉，全站其他点击的噪音也还在。
     - 报错监控以后要的话，单独开工单接正式的错误工具，不混在产品分析里。
   - **决定**：按建议（用户，2026-10-10：「全部同意你的」）
