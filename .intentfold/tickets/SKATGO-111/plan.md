# SKATGO-111 plan

## 代码里看到、工单没写的

- **牌桌：** 练习来源（SKATGO-110）照搬了整套牌桌：信息栏（含总分）、出牌提示语、下面的叫牌和合约面板、结算框。这些开关都在 `GameTable` 里，可以按「练习」关掉或替换。
- **牌高：** 嵌在页面里的牌桌高度是 token `dims.tableEmbedded`（640）。不改 token，只能靠收紧页面上方的间距，让整张牌桌留在屏幕内。
- **现成可用的：** 打分条用 kit 里的 `ProgressBar`；关卡格用设置里选牌背的那种网格模板 `dims.backChoices`；方块高度用 `dims.iconButton`。都不需要新 token。

## 路线

1. **`GameTable`：** 练习来源可以带四样东西：顶部内容 `top`（代替信息栏）、牌的对错 `verdicts`、发光的牌 `glow`、结束时浮在牌桌上的 `after`。练习模式下不显示提示语和侧边面板。
2. **`open-endgame.tsx`：** 分数条（庄家的分 = 底牌 + 吃墩，对 61）；记录每张出过的牌判对还是判错，出错时让能赢的牌发光；放完对手的牌之后显示 `after`。
3. **题目页：**
   - 标题改成一行「Karo · du bist Alleinspieler / du verteidigst」，去掉任务段落和下面的结果面板；
   - 结果做成小卡：解开 / 没解开、关键牌（后面某一步出错时是「这里只有某张能赢」）、下一关 / 为什么 / 再来；
   - 页面间距收紧。
4. **目录：** 明牌残局这一类改成关卡格；其他类型（已隐藏）保持原来的卡片。
5. **文案：** 新增的几条，删掉不再用的「Spiel es zu Ende」。
