# SKATGO-86 acceptance checks

在构建产物上跑（web 55086、multiplayer 56086、数据库 57086），Playwright 有头浏览器，桌面 1280×820 和手机 375×812。牌局由脚本走合法着法推进，只在浏览器里打最后一张牌。

## AC1 结束后的分数表
- **自由对局**：`/de/spielen` 打完一局（脚本走合法着法），结果里有 `daily-deal-scores` 表。它有 `you` 和 `ai` 两行，各三个座位的分数，`you` 一行的分数等于本局 Seeger-Fabian 分；AI 一行下面有这一局是什么的说明。
- **第 11 课**：同样检查一次，这一项只在桌面跑。
- **三家都 pass**：用 API 打一局三家都 pass 的自由对局，`/free/review` 返回带 `ai` 的结果（AI 有自己这一局，或者也是三家 pass）。

## AC2 重复请求结果一致
- 同一局的 token 连续请求两次 `/api/free/review`，两次的 `ai` 完全相同。

## AC3 加载和失败
- 加载：复盘请求返回前，结果里能看到加载提示，「下一局」按钮已经能点。浏览器里把 review 请求延后来观察。
- 失败：浏览器里让 review 请求返回 503，显示失败提示；玩家自己那一行和「下一局」照常。
