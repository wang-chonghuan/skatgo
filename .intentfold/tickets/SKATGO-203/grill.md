# SKATGO-203 grill

没有问题需要人回答。

## 替你决定的

1. 协会没有 logo，用什么图？——英国国旗。起初用协会网站边框上的德国牌橡子图；交付前的旁观评审指出橡子是德国牌花色，配"British"信号相反，像素图也和站内画风不符，于是换成英国国旗（与页头英文国旗的英国半边同一画法）。看图就能判断，验收时给人看截图（门槛第 3 条：能展示就不问）。决定者：agent。
2. 文案——英文 "Listed by"，德文 "Gelistet bei"，协会名两种语言都用英文原名。依据：人说 "listed by"；协会正式名称是英文。决定者：agent。
3. 位置——首页卡片之下、页脚之上，不进页脚。依据：人说「首页，底部」；SKATGO-198 定过外链不进每页页脚。决定者：agent。
4. 链接正常 follow，新标签页打开。依据：与 About 页推荐网站一致。决定者：agent。
