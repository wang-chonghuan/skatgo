# SKATGO-59 plan

## 代码里已有、工单没说的

- **引擎目前只在 Null 庄家吃墩时提前结束**（`game.ts` `collectTrick`），没有任何「认领」或「认输」的步骤。一步棋（`Move`）只能由轮到的那个座位出。
- **自由对局、第 11 课、每日赛都由服务器打**：
  - 浏览器只拿到玩家座位能看的东西（`seatView`）：自己的手牌、打过的牌、拿起后的底牌、Ouvert 庄家的牌；
  - 服务器（`computers.ts` `advance`）让电脑一直走到轮到玩家。
- **每一步都记下来，重放只走引擎**（每日赛 `daily_entries.actions`，自由对局在令牌里）。因此认领、认输也必须是记下来的一步，重放时才会得到同样结果；旧记录里没有这一步，照常重放。
- **一副的结果就是引擎打完的状态**（`finish` → `summarize`）。保存的摘要、「你对 AI」对比、当天总分、排行榜都从它来。只要提前结束的那副最终状态和真打出来一样，这些自然一致。
- **AI 对照局**（`benchmark`）也走同一个 `advance`（三个座位都是电脑）。今天、明天已经发好的日子存着对照局的步骤，不会再算。
- **桌面上轮到玩家出牌时**，信息板下面那行只有一句「你出牌」。那里没有别的按钮，可以放唯一一个 `go` 按钮（ui.md：一个视图最多一个 `go`）。

## 路线

1. **引擎**：新增 `app/src/lib/skat/rest.ts`。
   - **`restLine(game)`**：庄家在空墩上出牌、打花色或 Grand 时，用庄家看得见的牌判断剩余墩是否必然全归他。
     - 「看不见的牌」= 32 张减去庄家手牌、打过的牌、庄家已知的底牌。Hand 局底牌算看不见。
     - 判定规则：
       - 庄家每张王牌都比看不见的王牌大，或者剩下的王牌已经少到会被挤掉；王牌张数不少于看不见的王牌数，可以先把王牌清光；
       - 之后每门副牌，庄家的牌依次比对手可能留着的牌大。
     - 判定为真时，返回出牌顺序：王牌从大到小，然后每门副牌从大到小。
     - 这是充分条件：对手任何分布、任何出法都拿不到一墩。
   - **`nullBeaten(game)`**：Null 局在空墩时，庄家不管谁怎么出都吃不到墩（「稳赢」）。
     - 判定规则：每门花色里，庄家每张牌都比两位防守方在这门的每张牌小；轮到庄家先出时，他手里每门都有防守方能跟。
     - 用全部真实手牌判断。
   - **两种新步骤**（`Move`）：
     - `claim`：庄家认领剩下的墩；
     - `concede`：防守方放弃一个稳赢的 Null。
     - `applyMove` 收到这两步后，用引擎自己的 `playCard` / `collectTrick` 把剩下的牌打完：庄家按 `restLine` 的顺序出，其余座位出第一张合法牌。
     - 打出来的最终状态就是结算依据：牌点、Schneider / Schwarz、得分全部照常由 `finish` 算。
   - **`Game.early`**：可选字段，取值 `'claim' | 'concede'`，只用于结算面板的那句说明。旧状态没有这个字段，按正常打完显示。
2. **服务器**：
   - `model.ts` 的 `actionSchema` 加 `claim`。这是玩家能发的步骤；`concede` 只由服务器记录。
   - `applySeatMove` 允许防守方在空墩时 `concede`（不要求轮到他）。
   - `computers.ts` `advance`：每到空墩先检查：
     - 玩家的 Null 稳赢 → 由一位电脑防守方记一步 `concede`；
     - 按 grill Q3：电脑庄家的剩余墩确定 → 记一步 `claim`，或电脑庄家的 Null 稳赢 → 记一步 `concede`。
     - 每日赛、自由对局、第 11 课都走这里。
3. **桌面**（`game-table.tsx`）：
   - 玩家当庄家、空墩轮到他、`restLine` 为真时，那行「你出牌」旁边出现 `go` 的 block 按钮。点了发 `claim`。
   - 浏览器用同一个 `restLine` 和 `seatView` 判断，不需要服务器另给标志。
   - 结算面板第一行说明怎么结束的（`early`）。
   - 新增文案 `de` / `en` 各一套。
4. **测试**（`app/src/lib/skat/rest.test.ts`）：
   - 随机局面里，凡判定可以认领的，用穷举验证：按认领顺序出，对手任何出法、看不见的牌任何分布都拿不到一墩；
   - 凡判定稳赢的 Null，穷举所有人的所有出法，庄家都吃不到墩；
   - `claim` / `concede` 得出的最终状态等于手工把同样的牌打完；
   - 若干不能认领的反例。
