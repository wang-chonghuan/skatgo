# SKATGO-231 grill

没有问题需要人回答：每一条要么在人的原话、charter 或以前工单里有答案，要么是看截图就能判断、做出来给人看的外观选择。

## 替你决定的

1. **站点顶栏和页脚**：保留 SkatGo 的，只有论坛内容区换成 Geist。依据：人要的是"论坛"仿照 Vercel；ui.md 规定顶栏"每页都一样"。看截图即可判断，不对就返工。
2. **按钮和分区药丸**：用 Geist 的黑色（#171717），不用 SkatGo 的绿色。依据：人：「最好严格用它的论坛设计系统」。看截图判断。
3. **论坛首页**：原来的"全部"列表换成 Vercel 式总览：精选公告/教程 + 标签切换、教学视频一排、讨论流。依据：人："用vercel的设计，用我定的简洁结构"。
4. **教学视频卡片**：不显示 YouTube 缩略图，只有日期、"YouTube"和标题，点击在新标签页打开 YouTube。依据：Vercel 自己的视频行就没有缩略图；去 YouTube 取缩略图会把每个访客的地址发给 Google，现在全站只有 Google Fonts 一个外部请求。
5. **教程编号**：按发布顺序编号（第 1 篇最早），不加排序字段。依据：一条规则，最简单；以后要调顺序再说。
6. **空分区**：现在没有视频和教程，分区里显示一行"还没有……"。依据：结构是人定的四个分区，要能看到。
7. **夜间模式**：论坛用 Geist 自己的深色值（从 Vercel CSS 一起提取）。依据：全站有夜间模式（SKATGO-184），论坛不能在夜里刺眼。
8. **头像**：论坛没有用户头像（product.md：论坛不做头像/资料），用名字首字母的灰色圆形代替，大小照 Vercel（列表 40px，帖子 24px）。
9. **日期**：照旧显示日期，不显示"5 天前"。依据：日期要在服务器和浏览器上一样（现有规则）。
10. **字体**：Geist 和现有字体一样从 Google Fonts 加载，不下载文件，不加 npm 依赖（engineering Redline 3 不涉及）。
11. **分区页的收录**：照旧不收录（只有论坛首页和帖子收录）。教程总览做成可收录的 SEO 页面可以以后单开。
12. **发视频的方式**：官方在"教学视频"分区发帖，正文里放 YouTube 链接；没有新的表单。
13. **首页的"论坛"卡片文案**不动（人没指到那里）。
14. **搜索、点赞排行**：不做。依据：product.md 明确论坛不做搜索；人的结构里没有排行。
15. **令牌和 charter 修改的审批**：ui.md Redline 1（新令牌）和 product.md Redline 1（改产品意图）——人在本单的要求就是授权，已写进工单约束。
