# SKATGO-221 Grill

没有问题达到需要问人的门槛：要改的字（Hot）、金色、高光、会闪都在 Request 里由人定下；剩下的是看得见的视觉选择，按规则做出来给人看截图，不先问。

## 审批（不是 grill 问题）

- **`ui.md` Redline 1（token 注册表）**：金色奖杯和闪光必须新增颜色、时长和图形的值。人的要求「奖杯改成金色带高光的还会闪的」就是批准，同 SKATGO-186（人的颜色要求即批准）。新增的值在 handoff 里逐个列出。

## Decided for you

1. **德语横幅写什么？** "Hot"，不翻成 "Heiß"。依据：人点名要 "Hot"；德语里 "Hot" 作为标签常用，"Heiß" 读起来像温度。
2. **横幅的颜色、角度、位置变不变？** 不变，只换字。依据：人只要求改字；SKATGO-206 定下的红色斜彩带人当时认可过（「应该像彩带一样斜着，在右上角」）。
3. **奖杯怎么做？** 自己画 SVG（金色渐变、杯身白色高光、杯身一颗浅刻的星），不用联赛页的段位图片。依据：段位图片带整块底色，放不进卡片的图标位；SVG 在任何屏幕都清晰，颜色走 token。
4. **"闪"是什么样？** 一道斜白光每约 3 秒从左到右扫过杯身一次（约 1 秒扫完，然后停约 2 秒），旁边两颗小星星交替闪；外圈一层淡金色光晕。依据："会闪"＋"高光"；扫光是游戏里奖杯、金币常见的闪法，停顿避免一直晃眼（人在 SKATGO-134 说过讨厌页面上的干扰）。
5. **奖杯多大？** 和其他三张卡片的图标一样大（`icon.tile`，36px），星星画在框外一点。依据：四张卡片的图标对齐；金色实心本身已经比白色线条显眼。
6. **系统要求"减少动态效果"时？** 不动：光带不出现，星星常亮。依据：ui.md 规定 `bp.reducedMotion` 下动画关闭（SKATGO-29）。
7. **夜间模式？** 金色日夜不变。依据：ui.md「section tiles … the same day and night」。
