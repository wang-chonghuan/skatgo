## Decided for you

1. **Hide a name on the board?** Not built: the default name is already anonymous, the nickname is the player's
   privacy; chess.com and Lichess have no such switch, Duolingo only by leaving the leagues. Basis: the human —
   「我的问题你也先调查和决定」.
2. **Where in the settings?** The first section, above the deck: who you are, then how the cards look.
3. **An account with no name yet** sees an empty field and may set one; otherwise its first finished tournament gives
   it a random one, as before.
4. **Earlier boards** show the current name: the board reads the player's name now, the name stored with the entry only
   when there is none. Basis: 「改一次，整体都改」.
5. **The red line of SKATGO-90** (「禁止改变任何已经有的用户的名字」) is read as: the system never changes a player's
   name; a player's own change applies everywhere. Recorded in the ticket.
