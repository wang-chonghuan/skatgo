# SKATGO-57 grill

Grill：human，由人回答，下列建议是机器的推荐。

已定（开工前人同意）：叫牌由引擎按已存的步骤重放得出，不让 AI 重打，不删记录。

1. **结果面板的三层结构**：
   1. 一行结论，大字：「你 +40 · AI 0 · 差 +40」；
   2. 两栏对比「你 / AI」，每栏三行：
      - 叫牌：三人各叫到多少或 pass，例「你 20 · Lina 23 · Max passe」；
      - 定约：谁当庄、什么定约、胜负和牌点，例「Lina Grand · gewonnen 91:29 · Schneider」；
      - 分数：三人各自的 SF 分，例「你 0 · Lina +146 · Max 0」；
   3. 「详情」默认收起：局值计算、牌点拆分、底牌。

   当天累计表放在面板下方，默认收起（「Tagesverlauf · 3 Spiele」）；「下一副」按钮在最下面。
   - 建议：采纳。
   - 理由：第一眼就知道这副打得好不好；第二层说明为什么，叫牌和定约并排放；其余都是次要信息。
2. **原来开头的「This game is lost / gewonnen」大标题去掉**，改成第一层的分数结论。
   - 建议：采纳。
   - 理由：玩家当防家时，「输了」常常和自己的分数（0）对不上，正是你说的乱。分数比胜负句更直接。
3. **分数一律用 Seeger-Fabian**，与排行榜一致。不再单独显示「Lina 记 +96」这种一般计分，它挪进「详情」。
   - 建议：采纳。
4. **两栏在手机上上下排**（你在上、AI 在下），桌面左右并排。
   - 建议：采纳。
   - 理由：手机 375 宽放不下两栏三行内容，上下排不会横向滚动。
5. **全员 pass 的那副**也用同一块对比：你这边写「全员 pass · 0」，AI 那栏照常显示它那副的叫牌、定约和分数。
   - 建议：采纳。
6. **`/daily` 当天页和结果页的对比表**：展开的那一行也加上叫牌，其他不变。
   - 建议：采纳。
   - 理由：表和面板说法一致；工单重点是打完一副后的面板，表不重做。
7. **自由对局的结算面板不变**。
   - 建议：采纳。
   - 理由：工单只针对每日赛。
