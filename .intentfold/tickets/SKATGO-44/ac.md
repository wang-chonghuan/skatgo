# Executable Acceptance

## AC1: Stable Addresses

Run the shipped-site SEO checker against the built ticket server. Root must return German 200 under absent, German, English and other language headers and a saved English cookie. /de and /de/ must permanently redirect to root with query preserved. English remains 200 and self-canonical. Derived sitemap URLs and all reciprocal alternates must resolve directly to the expected 200 pages. Unknown paths and lesson slugs must return 404.

Headed browser language switching must retain page identity and land at the correct lesson slug or homepage.

## AC2: Readable Entries and Usable Game

With JavaScript disabled, derive every public page from sitemap and inspect visible main text, H1 and real internal links. German home, course, rules, play and daily must contain substantive truthful copy. With JavaScript enabled at both Operations viewports, verify the root navigation, lesson entry, free-play server game and daily entry work without horizontal overflow or hydration errors. Inspect screenshots; play retains full-screen table geometry before the reading section.

## AC3: Indexability and Structured Data

SEO checker must validate each derived canonical, language alternate, unique title/description, parsable truthful JSON-LD and referenced assets. Daily execution must have noindex and not appear in sitemap; its noindex policy must be shared with the route rather than a second route list. Negative checks must demonstrate that a broken canonical and missing content cannot pass.

## AC4: External Baseline and Follow-Up

Record the authenticated GSC observations already made, including report dates, German URL inspection statuses and canonical values, without treating delayed GSC metrics as current traffic. Record completed diagnostics separately from post-release URL live tests, sitemap reread and index requests. Release, Google processing and ranking outcomes remain pending, never passed.
