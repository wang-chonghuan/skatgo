# SKATGO-79 acceptance checks

在构建产物上跑（web 55079、multiplayer 56079、数据库 57079），本地数据库。牌局一律由脚本通过 API 走合法着法推进，不手动打牌。桌面 1280×820 和手机 375×812 两个视口都检查。

## AC1 每副的记分单
- 用脚本打完一副，打开牌桌看结果：记分单有「Du」和「AI」两行；每行的你、Lina、Max 三个数分别等于服务器回复里 `deals[i].scores` 和 `benchmarks[i].scores`；Saldo 等于 2·你 − Lina − Max。
- 两行的身份色不同（读计算后的颜色）。
- 结果里没有 Diff。

## AC2 整个赛的记分单
- 用脚本打完一个 6 副赛，打开 `/daily` 和牌桌最后的结果：有整个赛的记分单，你的局、AI 的局各一行；三家合计等于逐副相加，Saldo 按同一公式算。

## AC3 排行榜按 Saldo
- 本地准备几条打完并起了昵称的记录，其中一条用改动前的代码（`d27de36`）生成，并让「按总分排」和「按 Saldo 排」的名次不同。
- 通过：
  - 页面上的榜按 Saldo 从高到低排，并显示 Saldo；
  - 旧记录在榜上，名次按它的 Saldo；
  - 改动前后数据库里 `daily_entries` 的行数和内容（导出比对）完全相同。
