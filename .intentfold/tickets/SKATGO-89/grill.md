# SKATGO-89 grill

人说「不用grill」，所以工单是 `Grill: self`：agent 只依据 charter 和代码里看到的东西自行决定，下面每条都记了依据。

1. **十二条怎么翻？**
   - 决定：逐条直译成德语和英语，用德国 Skat 的说法（Stich、Trumpf、Alleinspieler、Gegenspieler、Buben、bedienen）。牌名按 app 的写法用 A、10、K、D、B，英语页也用 B、D（SKATGO-78 定的）。不加解释，也不加例子。
   - 依据：人说「我认为你不需要修改它」。
2. **课程页的卡片放在哪？**
   - 决定：放在简介下面、学习进度卡片上面，样式和课程卡片一样（白色选项卡片），不用绿色按钮。
   - 依据：人同意的是「学习页最上面」。进度卡片里那个绿色「开始/继续」按钮仍然是这一页唯一的主行动（ui.md：每个页面最多一个 go 按钮）。
3. **首页那行小链接什么时候显示？**
   - 决定：只在还没学过任何一课时显示，服务器渲染时也显示。
   - 依据：那块的标题是「Neu beim Skat?」；学过课的人在那里看到的是「继续第 n 课」。
4. **页面底部**
   - 决定：一个绿色「开始打牌」按钮去自由对局，下面是课程和规则两个链接。
   - 依据：人同意的方案。这也是这一页唯一的 go 按钮。
5. **charter**
   - 决定：
     - engineering.md、ui.md 补上这一页；
     - product.md 在课程那段补一句。product.md 的红线 1 要求人明确批准，这里依据的是人在 SKATGO-79 关单时的授权：「授权你改所有charter，移除不一致和矛盾的地方，写上最新的」。交付时会单独提出来请人确认。
